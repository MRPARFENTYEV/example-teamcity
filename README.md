### Запуск и настройка Teamcity + Teamcity-agent
В ходе выполнения задания по настройке CI/CD в TeamCity я успешно реализовал базовую часть пайплайна:

настроен и запущен сервер TeamCity и агент
подключён репозиторий
выполнена сборка проекта через Maven
реализована логика веток:
для ветки master выполняется mvn clean deploy
для остальных веток — mvn clean test

Сборки проходят успешно, тесты выполняются корректно, условия веток отрабатывают ожидаемо.

Однако на этапе интеграции с Nexus возникла проблема инфраструктурного уровня:   
в задании требуется убедиться, что артефакт публикуется в Nexus  
но ни один из доступных IP-адресов виртуальных машин не предоставляет доступ к Nexus по порту 8081 (HTTP-интерфейс не открывается)  
при попытке подключения по SSH к одной из машин (предположительно Nexus) получаю ошибку аутентификации по ключу (Permission denied (publickey)), что не позволяет проверить состояние сервиса  

Таким образом, на текущий момент отсутствует доступ к работающему экземпляру Nexus Repository Manager, что делает невозможным выполнение следующих пунктов задания:  

настройка settings.xml для деплоя  
публикация артефакта через Maven (mvn deploy)  
проверка наличия артефакта в Nexus
